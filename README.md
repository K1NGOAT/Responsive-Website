# Responsive-Website
## Description
A responsive three-page cafe website created using HTML and CSS. This project demonstrates my ability to build visually appealing and responsive web pages that adapt to various devices and screen sizes.

## Features
- Three distinct pages: Home, About, Menu
- Responsive design for all devices
- Clean and modern user interface

## Technologies Used
- HTML
- CSS

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/K1NGOAT/Responsive-Website.git
Download all the files and keep them in a new folder.

2. Open index.html in your web browser.

## Usage
- Navigate to index.html to view the home page.

- Use the navigation menu to explore the About and Menu pages.
